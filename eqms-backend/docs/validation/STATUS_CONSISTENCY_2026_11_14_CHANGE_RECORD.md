## Rules (the lifecycle of the Document Master)
- A revision is Obsoleted only after being Effective (a newer revision is published, the Document is obsoleted, or the Legacy Batch Import closes older historical revisions from Draft); a revision that was Effective is never Closed - Cancelled.
- A Document is Active iff it has an Effective revision; else Obsoleted if it has an Obsoleted revision; else Draft if it has an open revision; else Closed - Cancelled. An Obsoleted Document has no open revision.
- A live Controlled Copy belongs to an Effective revision.
- The system has no other statuses: Document 4, Revision 8, Controlled Copy 4, Uncontrolled Copy 3. Why something ended (Recalled, Lost, Damaged, Destroyed, Expired, Rejected, Cancelled) is a reason, never a status.
