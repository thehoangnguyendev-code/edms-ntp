# Change record: Report templates, approval only for GMP use, and the menu of the templates (REPORT-NON-GMP-NO-APPROVAL-2026-11-15)

> **Update 2026-11-15 (owner chose option A):** the rule "a template not used for GMP is in force when saved" described below was **removed** the same day; every template goes through approval. See Decision Log REPORT-ALL-TEMPLATES-APPROVED-2026-11-15. The menu, the revisions list, Reject and the notice to the author are unchanged. `ReportTemplateDatabaseTest` and `ReportTemplateRevisionActionsTest` now assert that every template waits for approval and that a template in force needs Upgrade; backend report, notification and menu tests 520 pass; frontend report tests 159 pass.



Status: built and checked on DEV; **not committed**. Owner decision: Decision Log `REPORT-NON-GMP-NO-APPROVAL-2026-11-15` (QA has not confirmed it).

## What changed
- A template not used for GMP decisions comes into force when it is saved (no Upgrade, no submission, no approver). A template used for GMP, before or after the change, keeps the full flow. Making a template GMP waits for approval as a Draft revision; taking it out of GMP needs Upgrade and approval.
- Migration V788: `report_template_revisions.approval_basis` (`APPROVED` | `NOT_REQUIRED`, default `APPROVED`).
- New API `GET /reports/templates/revisions` (the revisions of every template; filters status, GMP, data source; search; sort; paging; `scope=pending-approval`), a `gmp` filter and `gmpUse` sort on the template lists, and `approvalRequired`, `approvalBasis`, `inUseSince` on the template.
- Menu: Reports & Analytics gets Report Templates and Report Template Revisions (All Revisions, Pending My Approval); Report Definitions leaves Report Administration; the old `/settings/report-configuration/...` addresses redirect.
- Screens: GMP column in Report Templates and in Report Template Revisions; stepper of the revision on the page of a GMP template; not drawn for a revision nobody approved; Approved By / In Use Since / Changes Need Approval; the library shows Report Details only.
